# Electronic wooden fish

《电子木鱼：功德无量》是面向 Minecraft 26.3 单人世界的 Fabric 模组。右键敲木鱼积攒功德，有机会登上莲台，获得佛祖赐福。

[下载 1.1.3 模组 JAR](downloads/muyu-1.1.3%2Bmc26.3.jar?raw=true)

## 安装与合成

把发行版 `muyu-1.1.3+mc26.3.jar` 放入 Minecraft 26.3 的 Fabric 实例 `mods` 目录，同一实例安装 Fabric API 0.161.0+26.3。升级时请用新 JAR 替换旧版。打开单人世界，取得音符盒即可解锁配方。工作台支持左右镜像。

| 左 | 中 | 右 |
| --- | --- | --- |
| 空 | 空 | 木棍 |
| 任意木板 | 音符盒 | 任意木板 |
| 空 | 红石粉 | 空 |

放下木鱼，松开并再次按下使用键即可敲下一声。相邻两次有效敲击至少间隔 6 个游戏刻（通常为 0.3 秒）。每次都记 1 点基础功德。木槌下落，动作栏显示“功德 +1”、境界和总数。斧头拆除最快，生存模式下徒手也可回收。

1.1.2 的木鱼采用平顶方正红木，侧面刻游鱼和卷云。正面共鸣槽有独立的内壁和底面。木槌斜搁在后沿，敲击时浅木槌头落到顶面，3 个游戏刻后回弹。[木鱼与重剑实机对照](docs/relics-preview.png)

| 命令 | 用途 |
| --- | --- |
| `/muyu` | 查看功德、境界和距离下个境界所差的点数 |
| `/muyu history` | 查看飞升次数、最近一次的本地时间、最高功德和各项赐福的获得次数 |
| `/muyu claim` | 尝试领取莲台保管的物品 |
| `/muyu rehearse` | 需要作弊权限。功德不足 99 时补到 99，下次有效敲击必定触发完整飞升。该命令会产生真实死亡、物品和记录，适合测试存档 |

## 功德境界

每次有效敲击结算后，按当时的总功德单独判定一次。达到门槛的那一击就有机会飞升。功德写在当前世界的个人玩家数据中，以任意精度整数保存。拆除木鱼、普通死亡、飞升或重进世界都会保留账户。

| 境界 | 累计功德 | 每击飞升概率 |
| --- | ---: | ---: |
| 凡人 | 0～99 | 0% |
| 初窥佛门 | 100～499 | 0.01% |
| 功德圆满 | 500～1999 | 0.03% |
| 大彻大悟 | 2000～4999 | 0.08% |
| 立地成佛 | 5000～9999 | 0.15% |
| 功德无量 | 10,000 及以上 | 0.30% |

凡人的木鱼溅出木屑色火花。初窥佛门后敲击出现金光，功德圆满后会飘出莲花。最高境界每一击都会在玩家脚下画出一圈光粒。音高和粒子数量随境界提高。

## 飞升与赐福

木鱼自行连响，金莲从脚下升起。白光过后，玩家进入云殿，见到端坐莲台的佛祖。佛祖从独立的 15 条净土经文中等概率选一句，画面下方显示开示和经名。赐福之后，佛祖抬手点化，屏幕上出现《佛说阿弥陀经》的“应当发愿，生彼国土”。末尾的死亡画面和聊天栏显示“‘玩家名’上西天了”。正常帧率下，从第一声梵钟到死亡约 13.4 秒。

开示选自[《佛说阿弥陀经》](https://deerpark.app/cbeta/T0366)、[《佛说无量寿经》](https://deerpark.app/cbeta/T0360/2)和[《佛说观无量寿佛经》](https://deerpark.app/cbeta/T0365)。

| 赐福 | 权重（总计 100） | 作用 |
| --- | ---: | --- |
| 佛祖的苹果 | 47 | 直接复用原版附魔金苹果的食物和食用效果 |
| 神之碎片 | 30 | 用于合成神铸装备和在铁砧上修复有耐久的神铸装备 |
| 天命之钟 | 18 | 右键抽取一个异兆，冷却 60 秒 |
| 弑神之剑 | 5 | 满蓄力基础攻击伤害 24，是下界合金剑（8）的三倍。两者采用相同的剑类附魔规则与攻击速度 |

弑神之剑的两侧刃面呈墨青色和深蓝绿色，冷银锋口在刃肩处折出棱角。暗金枝纹从护手延伸至剑身下半部。金莲护手中央嵌有绛红宝石。手持和展示框使用 64 像素贴图，背包和快捷栏使用单独修整过的 32 像素图标。第一人称左右手均采用原版剑的持握位置、角度和缩放。

每次飞升只抽一件，允许重复。佛祖赐福时，宝物先记入这场仪式的玩家存档。死亡结算后，累计飞升次数增加，宝物转入待领取清单，重生时送入背包。背包已满时，腾出格子即可自动领取。其余物品、装备和经验继续执行世界原有的死亡规则。

云殿是本地客户端场景，佛祖使用独立的三维模型、贴图和动作。演出期间原世界不会生成建筑。按 Esc 可打开暂停菜单。途中保存退出，重进后会从前奏重播同一场仪式，沿用先前选定的宝物。完成飞升后照常继续积攒功德。

极限世界会给飞升死亡一次生存重生机会，保留原世界的极限难度。其他原因引起的死亡仍进入旁观模式。

## 神铸装备

拿到一枚神之碎片即可解锁 12 张工作台配方。头盔、胸甲、护腿、靴子、剑、镐、斧、锹、锄和长矛使用原版同类装备的摆法，金属材料换成神之碎片。马铠另用皮革，鹦鹉螺铠另用鹦鹉螺壳。神铸剑是可合成的装备，飞升奖励池仍单独提供弑神之剑。

整套装备采用深金、鎏金与浅金高光。胸甲正面刻八辐法轮，背面和头冠饰莲瓣，肩、膝与靴面有小莲纹。工具刃根带莲饰，柄上缠朱红细绳。马铠和鹦鹉螺铠也有独立的金色穿戴贴图。纹样沿用原版装备的轮廓与 UV 布局。[背包中的 12 件装备](docs/divine-inventory.png)

神铸装备以当前版本对应的下界合金物品为基准。耐久、可附魔性、采掘速度、满蓄力攻击伤害和盔甲的护甲值、韧性、击退抗性均取双倍。所有武器和工具的攻击速度沿用原版。例如神铸剑的基础伤害是 16，每秒攻击 1.6 次。实际减伤按原版属性上限和伤害公式结算。

长矛的刺击动画、蓄力起手和连续命中间隔沿用下界合金长矛。神铸长矛的攻击距离、动能伤害系数、冲锋窗口和对应的移动速度门槛均为双倍。工具继承原版采集等级、剥皮、造径、耕地等行为。有耐久的装备可以用神之碎片修理。

## 敲击异兆

冷却结束后，每次有效敲击有 0.90% 的机会抽取一个异兆。触发后冷却 6 秒。天命之钟使用同一组权重，每次摇钟都抽一个。自动回声只播放音效和敲击动作。飞升在同一击中优先，额外功德先入账，雷击等效果让位给演出。

| 异兆 | 抽中异兆后的权重 | 效果 |
| --- | ---: | --- |
| 功德加倍 | 16 | 额外记 10 点，敲击触发时共得 11 点 |
| 佛光普照 | 30 | 足下升起双层立体金莲，花瓣依次合拢成苞，由尖至根散为金色像素，全程约 3 秒 |
| 天降祥瑞 | 3 | 立即增加 4000 点经验 |
| 高僧点化 | 32 | 从 15 条经句中等概率抽一句，聊天栏显示经句和出处 |
| 天雷渡劫 | 2 | 雷光击中玩家一次，雷影视效不会引燃附近建筑 |
| 木鱼显灵 | 17 | 每隔 7 个游戏刻自动回应一声，共 4 声 |

敲木鱼和摇天命之钟触发高僧点化时，共用这 15 条经句。每句的机会都是 1/15，可以连续抽到同一句。云殿开示另用一组经文。

经文按汉译本节录。[《金刚经》](https://cbetaonline.dila.edu.tw/zh/T0235) · [《心经》](https://deerpark.app/cbeta/T0251) · [《法句经》](https://deerpark.app/cbeta/T0210/2) · [《佛说八大人觉经》](https://deerpark.app/cbeta/T0779) · [《佛遗教经》](https://deerpark.app/cbeta/T0389) · [《维摩诘所说经》](https://deerpark.app/cbeta/T0475/1)

### 金莲动画参数

参数位于 `src/client/java/local/muyu/client/LotusAnimation.java` 顶部。高度以方块为单位，时间以游戏刻为单位，每秒通常为 20 刻。

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `INNER_HEIGHT`、`OUTER_HEIGHT` | 2.20、2.42 | 内外层合拢时的花瓣高度 |
| `RISE_END`、`INNER_CLOSE` | 8、13 | 平展升起结束、内层开始翻起的时刻 |
| `OUTER_LAG`、`CLOSE_DURATION` | 4、21 | 外层延迟与每层合拢用时。增大后者会放慢合拢 |
| `DISSOLVE_START`、`DISSOLVE_END`、`END` | 42、55、60 | 花瓣开始消散、瓣根消散完毕和莲台淡尽的时刻 |

## 构建与测试

安装 JDK 25 后，在本目录运行以下命令。首次构建需要获取版本锁定的依赖。当前工作区也可用父目录自带的 JDK 和已准备好的 Gradle 缓存离线运行。

```powershell
$env:JAVA_HOME = (Resolve-Path '..\.tools\zulu25.36.205-ca-jdk25.0.4.1-win_x64').Path
$env:GRADLE_USER_HOME = (Resolve-Path '..\.gradle-user').Path
.\gradlew.bat --offline build
.\gradlew.bat --offline runClientGameTest
```

在其他机器上设置相应的 `JAVA_HOME` 后，使用 `gradlew.bat build` 和 `gradlew.bat runClientGameTest`。图形测试会打开游戏，在 `build/run/clientGameTest` 下创建测试存档和截图。发布 JAR 只需 Minecraft、Fabric Loader 和 Fabric API。PNG、模型和 Ogg Vorbis 音频已经打包，运行游戏无需准备绘图或音频工具。

### 游戏内复验

1. 新建允许作弊的单人测试世界。合成两只木鱼，分别放下。长按第一只，松开后敲第二只。用 `/muyu` 核对累计值，再拆掉一只，保存退出并重进。
2. 切换为生存模式，携带一件容易辨认的普通物品。执行 `/muyu rehearse` 并敲击剩下的木鱼。等佛祖说话、展示宝物和点化，查看死亡消息。重生后核对背包和 `/muyu history`。
3. 在下一次试演里，等赐福出现后按 Esc 保存退出。重进后观察相同宝物，等演出结束，确认本次只多一条领取记录。
4. 在测试世界开启 `/gamerule minecraft:keep_inventory true`，用圆石填满背包，再试演一次。重生后清出一格，等约 1 秒或输入 `/muyu claim`。圆石和其他原有物品应按原规则保留。
5. 测试天命之钟可用 `/give @s muyu:destiny_bell`。切换到空旷处右键，观察异兆和冷却。查询命令随时可用。

`build` 会执行境界边界、随机权重、超大功德、存档往返、重复结算和资源路径检查。逻辑测试逐值核对概率门槛和权重。客户端回归覆盖试演命令，也在测试存档里固定随机种子，通过正常木鱼交互命中万分之一的飞升判定。

### 首版实测结果

Windows 上通过了 `build runClientGameTest`。另将发行 JAR 装入全新的测试实例，使用本机已安装的 Minecraft 26.3 客户端再次验证了飞升、赐福、死亡与重生。两次运行均使用独立测试存档。

| 检查项 | 实测结果 |
| --- | --- |
| 合成、放置、长按与拆除 | 两种木板可混用。方块物品能放置，长按 24 刻只敲一下。换木鱼后功德累加，拆除后掉落一只木鱼。 |
| 仪式时序 | 佛祖在莲台上显形。额外点击会被锁定，打开暂停菜单时演出停留在当前画面。赐福后退出重进仍是同一件物品。 |
| 普通生存与满背包 | 关闭死亡保留时，随身钻石掉落，赐福在重生后到账。开启死亡保留时，36 格圆石完整保留，腾出一格即可领到托管宝物。 |
| 死亡播报 | 在显示和隐藏普通死亡消息的两种世界设置下，每场飞升的聊天播报都只有一条。 |
| 极限世界 | 持不死图腾也会完成飞升死亡，并返回生存模式。随后一次普通死亡仍进入旁观模式。 |
| 奖励和异兆 | 逐个核对了注册表内附魔对两把剑的判定、苹果的原版组件和六种天命钟结果。经验增加 4000，雷击造成实际伤害，冷却中的再次使用无额外收益。 |
| 资源 | 1.0.1 校验了 8 个方块状态、78 对中英文语言键、两组经文及模型纹理引用。发行包内的 6 段音效与 1.0.0 逐字节相同。 |

场景使用固定镜头、云殿像素背景和实时三维佛祖。第三方光影、整合包和不同音频设备的表现仍待实测。模型、PNG 与六种音效由本项目制作。1.0.1 的 15 条高僧经句、15 条佛祖开示和最后的点化经文均以文字呈现。

1.1.0 的客户端回归在测试世界用木鱼和天命之钟各自触发了佛光普照。测试覆盖第一人称平视木鱼、花中转头、F5 开合和横移跟随。12 件装备逐件通过工作台配方匹配、产物与原版属性对照。另在游戏中穿戴了四件人形护甲并手持神铸镐。[金莲实机对照](docs/golden-lotus-views.jpg) · [神铸装备穿戴](docs/divine-equipment.png)

游戏画面可对照[木鱼斜俯视](docs/wooden-fish.png)、[重剑手持与快捷栏](docs/godslayer-first-person.png)、[莲台对话](docs/lotus-court.png)、[佛祖赐福](docs/blessing.png)和[死亡界面](docs/westward.png)。
